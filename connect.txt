HOW TO CONNECT WITH BACKEND:

1. Import analyze() function from main.py
2. Pass resume_text and jd_text from API
3. Return JSON result

Example (FastAPI):

from main import analyze

@app.post("/analyze")
def analyze_api(data):
    return analyze(data.resume_text, data.jd_text)


HOW TO CONNECT WITH FRONTEND:

Frontend sends:
{
  "resume_text": "...",
  "jd_text": "..."
}

Backend returns:
{
  "resume_skills": [],
  "missing_skills": [],
  "job_match_score": 75,
  "ats_score": 80,
  "courses": [],
  "projects": [],
  "learning_path": []
}

Frontend uses this to draw charts and tables.
