# 🚀 Resume Analytics and Career Recommender

An AI-powered web application that analyzes resumes, extracts skills, provides career insights, and recommends suitable job roles based on user profiles and resume content.

---

# 📌 Project Overview

The **Resume Analytics and Career Recommender** system helps users improve their resumes and discover relevant career opportunities using Machine Learning and NLP techniques.

The application performs:

- Resume Parsing
- Skill Extraction
- Career Recommendation
- Resume Analytics
- Job Role Suggestions
- Personalized Insights

This project is designed to assist students, freshers, and professionals in identifying the best career paths based on their skills and resume data.

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/maaz81/Resume-Analytics-and-Career-Recommender.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd Resume-Analytics-and-Career-Recommender
```

## 3️⃣ Create Virtual Environment

```bash
python -m venv venv
```

## 4️⃣ Activate Environment

### Windows
```bash
venv\Scripts\activate
```

### Linux / Mac
```bash
source venv/bin/activate
```

## 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## 6️⃣ Run Application

```bash
python app.py
```
